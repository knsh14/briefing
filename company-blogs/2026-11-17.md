### [Using mathematics to validate network configurations](https://www.amazon.science/blog/using-mathematics-to-validate-network-configurations)
**公開:** 2026-11-11

WAN のセグメント分離を、パケットを流すサンプリング試験ではなく、自動推論でモデル上の全経路について検証する手法を紹介している。
AWS Cloud WAN のルートテーブル、アタッチメント、ポリシー文書を論理命題に変換し、到達性解析ツール Tiros に「どのアタッチメントがどの宛先 IP でどこに到達できるか」を問い合わせる。
ポリシー上で互いに遮断すべきセグメントの間に経路が 1 つもなければ検証は成功し、あれば運用者に警告する。

静的な解析なので、デプロイ済みのネットワークを 1 時間ごとに検証できる。

**読む価値:** 設定を論理式に変換して性質を証明するという AWS の自動推論の使い方が、ネットワーク分離という身近な例で分かる。

## Cloudflare

### [Kitesurf is now open source](https://blog.cloudflare.com/kitesurf-open-source/)
**公開:** 2026-11-13 | **著者:** Luís Duarte

Workers 上で動く AI エージェント向けのステートレスなブラウザ Kitesurf を、Apache 2.0 ライセンスで GitHub に公開した。
ブラウザのコンテナなしで、HTML の解析から CSS の適用、JavaScript の実行、スクリーンショットの描画までを担い、Chrome DevTools Protocol に対応するので Puppeteer などから接続できる。
中身は WebAssembly にコンパイルした Rust のパッケージ群で、Blitz が DOM とレイアウト、Stylo が CSS、Boa が JavaScript の実行（Dynamic Workers で動かせない場合の最後の手段）を担う。
手元で動かせるほか自分の Cloudflare アカウントにもデプロイでき、その場合はページごとの Worker を隔離して作るため Workers Paid プランが要る。

**読む価値:** Chromium を使わずにエージェント用のブラウザを組む構成を、実際のコードで確かめられるようになった。

### [Introducing Spend Management: Spending limits and alerts for Cloudflare](https://blog.cloudflare.com/spend-management/)
**公開:** 2026-11-13 | **著者:** André Cruz

従量課金の顧客向けに、支出の上限に達したら製品の実行を自動で止める Spend Management をベータで提供し始めた。

ループは、1 つのセッションを続けると文脈が膨らみ、毎回記憶なしで始めると同じ失敗を繰り返したため、毎回新しいセッションで構造化した引き継ぎを読む形にした。

**読む価値:** エージェントの指示を試行錯誤ではなく評価に基づくループで改善する方法と、反対向きのテスト群を組にする理由が分かる。
