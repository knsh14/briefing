### [Pruning LLMs Like a Physicist: Block Removal as an Ising Optimization Problem](https://huggingface.co/blog/MultiverseComputingCAI/pruning-llms-like-a-physicist-block-removal-as-an)
**公開:** 2026-09-21

Multiverse Computing が、LLM から削除する Transformer ブロックの選択を制約付き二値最適化問題、つまりイジングスピングラスとして定式化した論文を紹介している。
既存手法は各ブロックの重要度を独立に評価する平均場的な近似だが、実際にはブロック同士の削除の影響が相互に作用するので、損失の 2 次のテイラー展開で得たヘッセ行列の非対角成分としてその結合を扱う。
ヘッセ行列は小さな校正データで一度計算すれば済み、候補の評価はモデルを動かさない安価なエネルギー計算になるため、総当たりやオープンソースのタブーサーチで低エネルギーの候補を素早く得られる。
最低エネルギー状態が常に最良とは限らず、Llama-3.1-8B では 17 番目の励起状態が再学習後に基底状態を上回った。
Llama-3.3-70B-Instruct を 50% 圧縮した場合、最良の既存手法より MMLU で約 23 ポイント高い。

**読む価値:** LLM の圧縮手法を検討している研究者やエンジニアに、ブロック間の相互作用を考慮すると深い圧縮でどれだけ差が出るかを示してくれる。

### [Migrating the GitHub Copilot runtime to Rust, using Copilot](https://github.blog/ai-and-ml/generative-ai/migrating-the-github-copilot-runtime-to-rust-using-copilot/)

### [We just shipped support for the ugliest part of HTTP: Vary](https://blog.cloudflare.com/vary-support/)
**公開:** 2026-09-22 | **著者:** Zaidoon Abd Al Hadi

Cloudflare の Cache Rules が、全プランで Vary ヘッダーに対応した。
Vary はレスポンスに影響しうるリクエストヘッダーをキャッシュに伝えるが、どの違いが本当に意味を持つかは伝えないため、生の値で区別すると同じ内容のエントリーが数千に分かれ、キャッシュがほとんど再利用されなくなる。
約 5 万の人気サイトの 1 億 2 千万件超のレスポンスを分析すると、約 3,000 サイトが 4 つ以上のフィールドで Vary を使い、47 フィールドに及ぶ例もあった。
新機能では、Vary に挙がったヘッダーごとの扱いを利用者が選べる。
選択肢は、既知のヘッダーを正規化する normalize、値をそのまま区別する passthrough、キャッシュを使わない bypass の 3 つである。

**読む価値:** 言語や画像形式でレスポンスを出し分けるサイトの運用者に、Vary によるキャッシュの断片化を防ぐ考え方と設定を示してくれる。

### [Python Workers are now generally available](https://blog.cloudflare.com/python-workers-ga/)
**公開:** 2026-09-21 | **著者:** Hood Chatham

Cloudflare Workers で Python を動かす Python Workers が、発表から 2 年で一般提供になった。
