### [Building the Agent Host Protocol for sessions that continue across devices](https://github.blog/engineering/engineering-principles/building-the-agent-host-protocol-for-sessions-that-continue-across-devices/)
**公開:** 2026-11-17 | **著者:** Rob Lourens

GitHub Copilot でエージェントのセッションを別のデバイスに引き継ぐための Agent Host Protocol（AHP）の設計を解説している。
VS Code の拡張機能として動いていた従来の Copilot はウィンドウに寿命が縛られ、製品ごとに個別の連携も必要だったため、複数のクライアントと複数のエージェントをつなぐ共通プロトコルを作った。
AHP はエージェントの動作には立ち入らず、機能の単位を URI で識別するチャネルとし、各チャネルの状態をサーバーが裁定する reducer ベースのオブジェクトで持つので、通信が切れても再接続と再送で整合を取りやすい。
VS Code 側は TypeScript、GitHub 側は Rust で別々にホストを実装し、互いの独自拡張を棚卸しする過程でプロトコルの不足や誤った前提を見つけた。
ライブラリは Rust や TypeScript など 6 つの言語で提供されている。

**読む価値:** 複数のクライアントから同じエージェントのセッションを扱うためのプロトコル設計の判断を、2 つの独立した実装の経験とともに知ることができる。

**読む価値:** ログのパイプライン運用をエージェントへ任せるとき、変更前の検証と人の承認をどこに置くかを考える参考になる。

### [How Datadog resolves evolving OpenTelemetry semantics at query time](https://www.datadoghq.com/blog/engineering/semantic-translation-otel/)
**公開:** 2026-11-19

OpenTelemetry のセマンティック規約の変更（http.method から http.request.method への改名など）や Datadog 独自の規約が混在しても、同じクエリで扱えるようにする仕組みを解説している。
名前の対応表だけでは足りず、同じ概念でも単位やメトリクスの型が違ったり、特定のタグがあるときだけ等価だったりするため、等価関係とその成立条件を知識グラフ Semantic Core で表す。
例えば OTel の system.cpu.utilization と Datadog の system.cpu.user は、state:user のタグ条件と 0〜1 から 0〜100 への換算を付けて初めて等価になる。
グラフから事前に計算した設定を SDK が持ち、実行時にクエリをメモリ上で書き換え、結果もクエリ側の語彙にそろえて返す。
等価関係は各領域の担当チームが定義し、複数の構成で同じシナリオを流す外部の検証器で実際のテレメトリと照合する。

**読む価値:** 計装の規約が混在する環境で、保存データを書き換えず、問い合わせの時点で意味をそろえる設計を学べる。
