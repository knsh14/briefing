### ![PR](icons/git-pull-request.svg) [feat(multicursor): zq operator; cursor-local marks](https://github.com/neovim/neovim/pull/42148) `#42148`

**概要:** `Q` が演算子ではないため `[count]Q` や `{Visual}Q` が場当たり的に実装されていたこと、`Q` が常にトグル動作で冪等でないこと、`'.` や `'[` などカーソル相対のマークがカーソルごとに保存されず cascade 中に機能しないことを解決する。`{motion}` で到達できる全位置にカーソルを置く `zq{motion}` 演算子を導入し、`{Visual}Q` は `{Visual}zqj` の別名とした。冪等なカーソル配置として `1Q` と `2Q` を追加し、`zqgn` と重複する `[count]Q` は廃止した。カーソル相対マークは `type=motion` に分類し直し、cascade 中にカーソルごとに保存して復元する。

**直近のアクティビティ:** 対象期間のコメントなし。マージ済み。

**変更ファイル:** 19 ファイル、+780/-409。`src/nvim/mcursor.c` の大幅な拡張、`src/nvim/context.c` と `normal.c` でのマーク保存処理の変更、`runtime/doc/repeat.txt` のドキュメント更新、`mcursor_spec.lua` のテスト大幅改訂。

### ![Issue](icons/issue-opened.svg) [[Bug] RP2040 SIO driver: split link permanently dies after USB replug/bus-reset (fixed upstream in ChibiOS, not yet synced into lib/chibios)](https://github.com/qmk/qmk_firmware/issues/26486) `#26486`
**ステータス:** Closed | **ラベル:** bug, help wanted

**概要:** RP2040 の分割キーボードで USART 全二重の分割通信を使うと、マスター側の USB を抜き差ししたり KVM を切り替えたりした後、スレーブ側が恒久的に応答しなくなるという報告である。コンソールには `SPLIT: receiving handshake failed` が繰り返し出力され、マスターをリセットするまで回復しない。報告者は、`lib/chibios` の `hal_sio_lld.c` が古く、割り込みマスクのビット取り違えを直した upstream ChibiOS のコミットが入っていないことが原因だとし、その取り込みを提案した。

**直近のアクティビティ:** 報告者自身が、手元の環境が upstream に追いついていなかったと謝罪し、クローズした。

**次のアクション:** クローズ済みである。
