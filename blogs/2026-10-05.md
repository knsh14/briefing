## Simon Willison

### [We're going to need default hard budget caps on pretty much everything](https://simonwillison.net/2026/Oct/3/default-hard-budget-caps/)
**公開:** 2026-10-03

従量課金のサービスや API には、一定額を超えたら停止してエラーを返すハードな予算上限が必要で、それを既定にすべきだと主張する記事。
コーディングエージェントや個人向けエージェントのおかげで、有料 API やホスティングを使うコードを手軽に動かせるようになり、暴走したサービスが寝ている間に数百から数千ドルを使う危険が増えたという。
警告メールを送るだけのソフトな上限では不十分で、上限を外したい人だけが明示的にオプトアウトする形がよいとしている。
AWS は 9 月 16 日、プロジェクト単位の月間支出上限を一部の顧客へ提供し始め、Google Cloud も 7 月に Spend Caps を出したことを紹介している。
エージェントがハードな上限のあるプロバイダーを優先して勧め、上限のないサービスの危険を初心者へ警告するようになってほしいとも書いている。

**読む価値:** エージェントにクラウドや有料 API を使わせる開発者は、想定外の請求を防ぐ設計の考え方と、AWS や Google Cloud の新機能を知ることができる。

## Latent Space

### [[AINews] not much happened today](https://www.latent.space/p/ainews-not-much-happened-today-cee)
**公開:** 2026-10-03 | **著者:** Latent.Space

2026 年 10 月 1 日から 2 日の AI ニュースをまとめた回。
OpenAI の GPT-6.1 Sol は入力 100 万トークンあたり 2 ドル、出力 10 ドルで、Astra の 5 分の 1 の価格だ。
Agent Arena では GPT-6 Sol より 39% 安く、スコアは 1.52 ポイント高いとされる。
Sonnet 5.5 は Agent Arena で 3 位、Chat カテゴリで 1 位に入った。
ただしタスクあたりのコストは 2.74 ドルで、Opus 5.5 の 1.58 ドルより高く、パレートフロンティアには乗っていない。
研究では、Hugging Face のマルチハーネス RL が紹介されている。同じ重みでもハーネスによってスコアが 62% と 33% に分かれるという結果と、LFM2.5-2.6B を 4 つのハーネスで 42% から 54% に改善した結果が載っている。
ほかに、llama.cpp の決定モデル向けエンドポイント、Claude Code の mods、T3 Code のオーケストレーター書き換え、長文脈での精度低下の研究なども扱っている。

**読む価値:** モデルやエージェント基盤を選ぶ開発者は、新モデルの価格対性能とハーネス依存性に関する最新の数値をまとめて確認できる。
