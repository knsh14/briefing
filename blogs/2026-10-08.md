### [Claude Haiku 5.5](https://simonwillison.net/2026/Oct/7/claude-haiku-5-5/)
**公開:** 2026-10-07

Anthropic が低価格モデル Claude Haiku 5.5 を公開した。
価格は 100,000 トークンまで入力 $0.10、出力 $0.50 で GPT-6 Luna と同額だが、それを超えると 5 倍になる。
新しいトークナイザーにより同じプロンプトのトークン数が Haiku 4.5 の約 1.25 倍になり、実質的な値上げも含まれる。
推論は無効化できず、low の pelican SVG は 0.0936 セント、max は 5 分 9 秒かかって 3.3826 セントだった。
あわせて Sonnet 5.5 のキャッシュ読み取りの半額化と、Max/Team プランへの毎月の API クレジット付与（繰り越し不可）も発表された。

**読む価値:** 低価格 LLM の選定で、Haiku 5.5 と GPT-6 Luna の価格構造の違いを具体的な数字で比べたい人に役立つ。

## The Pragmatic Engineer

### [Building resilient systems with Sam Newman](https://newsletter.pragmaticengineer.com/p/building-resilient-systems-with-sam)
**公開:** 2026-10-07 | **著者:** Gergely Orosz

『Building Microservices』の著者 Sam Newman を招いたポッドキャスト回。
Sam はマイクロサービスを「最後の手段」のアーキテクチャと呼び、その定義を「独立してデプロイできること」と「業務ドメインに沿った境界」の 2 つで説明する。
分散システムの誤謬を「情報の伝達には時間を要する」「通信相手は不在のこともある」「リソースは有限」の 3 つにまとめ、障害の多くは 3 つ目のリソース枯渇から起きると述べる。
冪等性の実装では、冪等キーはきれいだが後付けが難しく、フィンガープリントは後付けしやすいが正当なリクエストを重複と誤判定しうるという違いを挙げる。
AI については、ベンダーやモデルを差し替えられる設計にしておき、LLM の機能を決定的なコードに置き換えられないかも検討すべきだとしている。

**読む価値:** 分散システムやマイクロサービスを設計するエンジニアが、障害原因と冪等性の実装方針の判断材料を得られる。

### [The state of the tech industry in 2026](https://newsletter.pragmaticengineer.com/p/the-state-of-the-tech-industry-in)
**公開:** 2026-10-06 | **著者:** Gergely Orosz

LDX3 での基調講演をもとに、テック業界の現状を「変わったこと」「壊れたこと」「変わらないこと」「次に来ること」に分けて整理する記事。
変わったこととして、手でコードを書く人はほとんどいなくなり、5〜10 のエージェントを並行して動かす働き方が広がっている点を挙げる。
GitHub のデータでは、エージェントが作成した PR は 8 か月で 9 倍に増え、2026 年 8 月には人間の PR を上回った。
Linear でも 7 月以降はエージェントが作成した Issue が人間を上回り、Factory AI ではユーザーの 83%がスキルを使っている（2 月から 2.5 倍）。
壊れたこととしては、コードレビューの形骸化や品質と信頼性の低下を挙げている。

**読む価値:** エンジニアリング組織のリーダーが、AI エージェント導入の実態を GitHub や Linear の未公開データで把握できる。

## Latent Space

### [Can a Cloud-Native Harness Make Agents Reliable Beyond the Desktop?](https://www.latent.space/p/stacklok)
**公開:** 2026-10-07 | **著者:** Richard MacManus

Kubernetes を生んだ Craig McLuckie と Joe Beda が率いる Stacklok の取り組みを紹介する記事。
同社のオープンソースのハーネス Mecatl は、エージェントループをクライアント、モデルプロバイダー、状態ストア、実行環境から切り離し、クラウドで運用することを前提に設計されている。
Beda は、デスクトップ向けのハーネスを VM やコンテナに載せ替えるだけでは、エージェントのライフサイクル管理や人間の入力待ちでの一時停止が難しいと指摘する。
ほかに MCP サーバーを運用、統制する ToolHive と、アクセス制御や予算を管理する AI Gateway があり、商用製品はこれらを束ねて認証、認可、ポリシー、監査を提供する制御プレーンだという。
狙いは、Kubernetes がクラウド事業者への依存を減らしたように、企業がフロンティアラボへの依存を減らせるようにすることだという。

**読む価値:** コーディングエージェントを大組織で運用する方法を検討している人が、クラウドネイティブなハーネスの設計思想を知ることができる。

### [[AINews] Quasi-Riemann-Hypothesis: OpenAI publishes 722 math papers solving 90 of the top 500 open math problems; “the most significant moment” in >100 years of mathematics](https://www.latent.space/p/ainews-quasi-riemann-hypothesis-openai)
**公開:** 2026-10-07

OpenAI が未公開の社内モデルによる数学の成果として、722 本の論文を GitHub で公開した。
約 4,000 の研究課題を評価した結果で、1 件あたり平均約 3 時間の ChatGPT Pro の計算で得られたという。
Quasi-Riemann 予想などが注目され、数学者の Levent Alpöge は「数学史上最も重要な瞬間」と評価した。
一方で、誤りを含む結果もあるはずだという指摘や、検証しやすい数学やコードでの成果が他の分野に一般化するのかという疑問も出ている。
ほかに、Mistral Large 4（総パラメータ 1T、アクティブ 49B）の公開、EmbeddingGemma 2、Nano Banana 2.1、OpenAI Decisions API などを扱っている。

**読む価値:** AI による数学研究の成果と、それに対する専門家の評価と懐疑をまとめて押さえたい人に役立つ。
