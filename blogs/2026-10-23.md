**公開:** 2026-10-21 | **著者:** Gergely Orosz

### [What’s the ROI of software engineers’ spending on AI?](https://newsletter.pragmaticengineer.com/p/whats-the-roi-of-software-engineers)
**公開:** 2026-10-20 | **著者:** Gergely Orosz

2026-10-21 のダイジェストで取り上げた記事であり、公開時刻が対象期間の境界にかかったため再掲する。
27 社への聞き取りと CodeRabbit、Gitar の集計データから、開発者 1 人あたりの AI 支出と PR 数の変化を調べている。
CodeRabbit では週あたり PR 数が 1 年で 113% 増え、企業規模と支出には相関がなかった。
支出は 6〜7 月をピークに下がり、量的トレーディング企業では月額支出が 1 月の 50 万ドルから 9 月の 800 万ドルに増え、ROI はデスクの損益で判断している。

**読む価値:** 自社の AI ツール予算を他社と比べたいエンジニアリングマネージャーに、具体的な金額と PR 数の比較材料を与える。

### [Claude Mods: Flipping the Harness Inside Out](https://www.latent.space/p/claude-mods)
**公開:** 2026-10-21 | **著者:** Dan McAteer

Claude Code を自分のワークフローに合わせて変えられる Claude Mods を数週間使った体験記である。
mod は TypeScript か JavaScript の関数からなるプラグインで、プロンプト、ツール呼び出し、画面描画といったイベントに反応し、表示や振る舞いを差し替える。
著者は、エージェントと機械をつないでいたハーネスが人の注意に向けたインタフェース（Attention Interface）に変わりつつあり、mod はその向きを反転させるものだと主張する。
例として、メインエージェントを横で監視して見落としを知らせる組み込みの You Should Know が、未コミットの作業を誤って捨てる事態を防いだ事例を挙げる。
ChatGPT の Intelligent UI や Cursor の PR Routing & Approval と比べ、誰が Attention Interface を設計するかが違いだと整理している。

**読む価値:** コーディングエージェントのハーネスを、人が注意を向ける場所の設計として捉え直したい開発者に向く。

vLLM チームは同条件の GB200 でデコードのスループットが DeepInfer の公表値の 6% 以内に収まったと報告し、DeepSeek の効率が既存エンジンでは届かないという見方に留保をつけた。
prefill、decode、画像エンコードを分ける構成や、計算量の見積もりに基づくスケジューリングなどの設計も解説している。

**読む価値:** 大規模な LLM 推論サービスの設計と収益性の試算、その前提の危うさをまとめて知りたいインフラ担当者に向く。

## Martin Fowler

### [Fragments: October 21](https://martinfowler.com/fragments/2026-10-21.html)
**公開:** 2026-10-21 | **著者:** Martin Fowler

Fowler が気になった話題を短くまとめる回である。
まず、少しでも AI を使った文章は全部 AI 製と見なされうるという Gergely Orosz の指摘に同意しつつ、自分の AI 検出の精度や、翻訳などの正当な用途を切り捨てていないかという留保を述べる。
次に、多様性施策への逆風で資金が減り、Grace Hopper Celebration が今年中止になったことを惜しんでいる。
最も長いのは、Cindy Sridharan の記事「How to effectively debug when you no longer understand the code」の紹介である。
エージェントにはまずコードを読ませず、証拠を集め、バグが出ない対照群と比べて重要な事実を選び、すべての事実を満たす仮説を検証させるという手順である。
人向けのダッシュボードを役立たせる集約が、エージェントにとっては信号の価値を損なうという指摘も紹介している。

**読む価値:** コーディングエージェントでデバッグするときに人が何を指示すべきかを知りたい開発者に向く。
